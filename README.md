# BNCC MAP - แผนที่วิทยาลัยพณิชยการบางนา

เว็บแอปพลิเคชันแผนที่นำทาง ค้นหาอาคาร และห้องเรียนภายในวิทยาลัยพณิชยการบางนา (Bangna Commercial College)

## 🌟 คุณสมบัติเด่น (Features)
- 🧭 **ระบบนำทางอัจฉริยะ:** คำนวณเส้นทางหลบอาคารและสิ่งกีดขวาง พร้อมลูกศรชี้ทิศทาง
- 📏 **คำนวณระยะทาง & เวลาเดิน:** บอกระยะทางรวมเป็นเมตรและเวลาเดินเท้าโดยประมาณ
- 🛰️ **สลับแผนที่ดาวเทียม:** เลือกดูแผนที่ลายเส้นปกติ หรือภาพถ่ายดาวเทียมความละเอียดสูง (Esri)
- 📍 **ติดตาม GPS & เข็มทิศหมุนตามจริง:** แสดงตำแหน่งปัจจุบันพร้อมหัวลูกศรหมุนตามทิศทางหน้าจอมือถือ (DeviceOrientation)
- 🔍 **ค้นหาห้องเรียน & อาคาร:** ค้นหารายชื่อห้องเรียน อาคาร และแปลนชั้น
- 📲 **รองรับ PWA (Progressive Web App):** สามารถกด "เพิ่มลงในหน้าจอหลัก" เพื่อติดตั้งเป็นแอปมือถือได้ทันที

## 📁 โครงสร้างโปรเจกต์
```text
bncc-map/
├── index.html       # ไฟล์หลักของเว็บแอปพลิเคชัน
├── manifest.json    # ไฟล์ตั้งค่า PWA สำหรับการติดตั้งบนมือถือ
├── README.md        # รายละเอียดโปรเจกต์
└── images/          # โฟลเดอร์เก็บรูปภาพอาคารต่างๆ (b1.jpg - b13.png)
```

## 🚀 วิธีเปิดใช้งานออนไลน์ (GitHub Pages)
1. สร้าง Repository ใหม่บน GitHub ตั้งชื่อว่า `bncc-map`
2. อัปโหลดไฟล์ทั้งหมดลงใน Repository
3. ไปที่ **Settings > Pages**
4. เลือก Branch เป็น **main** แล้วกด **Save**
5. รอระบบสร้างลิงก์ `https://<your-username>.github.io/bncc-map/` เพื่อเข้าใช้งาน
